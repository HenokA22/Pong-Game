# Pong Game

This project is a JavaScript-based Pong game with both single-player and two-player modes. 
Built using HTML, CSS, and JavaScript, it features smooth paddle controls, dynamic ball movement, and real-time gameplay updates. 
Players can choose between competing against an AI or another player, with collision detection and ball physics adding complexity. 
The game includes a start screen, pause, and reset functionality, providing an engaging and responsive experience.
